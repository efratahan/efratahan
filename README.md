### Things you can open

**[Editing Reality](https://efratahan.github.io/editing-reality/)** — a room rebuilt from one
handheld phone video, then edited. A network I trained from scratch finds the walls, doors and
windows in the room map, and scores as high as Meta's SceneScript and Manycore's SpatialLM, or
higher, in every room. Move the furniture and the room changes with it.

**[Heart conduction model](https://efratahan.github.io/heart-conduction/)** — electrical conduction
simulated on real human-heart anatomy, with the 12-lead ECG computed from it, so every wave is
explained by which muscle fires and which way.
